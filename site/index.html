P · A · M · C

Вектор и булевы операции

Кривые Безье, перо, карандаш с авто-сглаживанием, конструктор фигур, нож, составные контуры (Ctrl+8) и 5 булевых операций: unite, subtract, intersect, exclude, divide.

B · Trace

Умные примитивы и векторизация

Эллипс, скруглённый прямоугольник, многоугольник, звезда и капсула с живыми параметрами. Встроенная трассировка растра (Image Trace) в Ч/Б и цветном режиме.

Warp · 3D

Живые эффекты в инспекторе

Редактирование без модальных окон: Warp, ZigZag, Roughen, Round Corners, 3D-поворот и экструзия, размытие по Гауссу, тень, свечение и разбор оформления (Expand).

T · Font

Текст, кириллица и свои шрифты

6 встроенных семейств (Inter, Manrope, Golos Text, Playfair Display, JetBrains Mono, Unbounded), импорт .ttf/.otf/.woff2 в проект, текст по контуру и перевод в кривые.

Ctrl+K

ИИ-ассистент и Preflight

Управление сценой через Tool Calling, перекраска по палитре референса и проверка макета (контраст, кегль под 300 dpi, выход за артборд). Gemini, Anthropic, Ollama и OpenAI-совместимые API; откат одним Ctrl+Z.

.locus · .ai · .psd

Импорт, экспорт и автосохранение

Импорт редактируемых .svg (включая Drag & Drop), хранение в .locus (ZIP со шрифтами и ресурсами), экспорт в .svg, векторный .ai (PDF), многослойный .psd, .png/.jpg.

Работает полностью на твоей машине

Проекты, шрифты, изображения и настройки никуда не отправляются. Встроенная «Академия» (F1) помогает освоиться за 5 минут с подсветкой нужных кнопок интерфейса.

Запуск из исходников (Node.js 20+ и Rust) 
git clone https://github.com/qualbyyy/locus.git && cd locus && npm install && npm run tauri dev

Для веб-версии без Tauri используй npm run dev. На Wayland бинарник сам выставляет WEBKIT_DISABLE_DMABUF_RENDERER=1.
