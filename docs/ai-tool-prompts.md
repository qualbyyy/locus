# Примеры для проверки инструментов ИИ

Как проверять: откройте приложение → `Ctrl+,` → вкладка «ИИ» → выберите провайдера и модель → `Ctrl+K` → вставьте промпт. Каждый запуск — один шаг `Ctrl+Z`; отменяйте сцену между проверками.

Крестик в окне ИИ не прерывает задачу: окно сворачивается, а внизу справа появляется индикатор с шагом и последним действием. Клик по индикатору возвращает окно, квадрат — останавливает ИИ.

Чтобы модель не выбирала другой инструмент, называйте его прямо: «используй `create_line`», «примени `boolean_op`».

## По одному инструменту

| Инструмент | Пример промпта | Что должно получиться |
| --- | --- | --- |
| `create_blob` | Добавь кляксу радиусом 180 в центре артборда, заливка #2f5d62, 9 точек, wobble 0.2. | Один замкнутый контур с плавными узлами, слой в панели слоёв. |
| `create_shape` | Создай звезду по центру: 7 лучей, 240×240 px, внутренний радиус 0.45, заливка #e9c46a, поворот 12°. | Фигура-звезда с 14 узлами, повёрнута. |
| `create_line` | Нарисуй три белых уса слева от центра: линии от (300, 620) через (420, 640) к (520, 650), толщина 5, скруглённые концы. | Открытые контуры только с обводкой, без заливки. |
| `report_plan` | Сделай постер из фона, двух подложек, заголовка и трёх акцентов. | Первым делом модель вызывает `report_plan`, и прогресс показывает реальное число шагов, а не 8. |
| `create_text` | Добавь заголовок «LOCUS» по центру сверху, Unbounded Bold 72 px, выравнивание по центру. | Текстовый слой, шрифт и вес в инспекторе. |
| `update_layers` | Перекрась выделенный слой в #b83b2e, прозрачность 0.6 и поверни на 15°. | Изменились только эти свойства, остальное на месте. |
| `delete_layers` | Удали выделенный слой. | Слой исчез; `Ctrl+Z` возвращает его. |
| `duplicate_layers` | Дублируй выделенную кляксу со сдвигом 40 вправо и 20 вниз. | Появился слой «… копия» со сдвигом. |
| `reorder_layers` | Отправь выделенный слой на задний план. | Слой стал первым в списке (нижним). |
| `set_clip_mask` | Сделай выделенный эллипс маской для текста под ним. | У текста появляется `↳ Mask`, заливка маски не рисуется. |
| `randomize_anchors` | Искази выделенную фигуру с интенсивностью 8 и seed 42. | Узлы сместились, число узлов не изменилось; повтор с тем же seed даёт тот же результат. |
| `align_layers` | Выровняй выделенные слои по центру артборда. | Общий bbox слоёв отцентрирован по артборду. |
| `apply_palette` | Перекрась все векторы и текст в палитру #1c1b1a, #da7756, #e9c46a, фон — #f5f2eb. | Цвета распределились по слоям, фон изменился. |
| `boolean_op` | Объедини выделенные пересекающиеся фигуры через unite. | Осталась одна фигура с общим контуром. |

## Изображения (vision)

- Прикрепите картинку скрепкой в окне ИИ: появятся превью и счётчик 0/4. Поддерживаются PNG, JPEG и WebP до 8 МБ.
- Если модель не поддерживает изображения, под превью появится предупреждение, а кнопка «Выполнить» заблокируется.
- Для проверки используйте vision-модель (`gpt-6-luna`, `claude-sonnet-5-5`, `gemini-4-neon`, `llava` и т.п.): «Опиши композицию на фото и повтори её тремя фигурами и текстом».

## Комплексные сценарии

### 1. Кошачья морда (проверка контраста и `create_line`)

> Чёрная кошачья морда по центру артборда: голова-клякса радиусом 230, два уха-эллипса сверху, белые глаза, нос цветом #da7756, по три белых уса с каждой стороны линиями `create_line`, подпись «LOCUS CAT» сверху. Не объединяй глаза, нос и усы в общий силуэт.

Ожидаемо: 8+ слоёв, детали читаются на чёрном, усы — открытые контуры с обводкой, `Ctrl+Z` откатывает всё сразу.

### 2. Постер (проверка композиции и 8 шагов)

> Сделай постер 1080×1080 в тёплой бумажной палитре: крупная фоновая форма, две контрастные подложки с прозрачностью, заголовок «ТИШИНА» и подзаголовок, 2–3 акцентные кляксы, всё выровнено по сетке.

Ожидаемо: 6–10 слоёв, есть иерархия текста, подложки полупрозрачные, элементы перекрываются осознанно.

### 3. Обложка с маской (проверка `set_clip_mask` + `boolean_op`)

> Сделай абстрактную обложку: большой круг, вычти из него второй круг со сдвигом, полученную форму используй как маску для текста «FORM», добавь акцентную полосу снизу.

Ожидаемо: составной контур с отверстием, текст обрезан формой, маска снимается кнопкой в инспекторе.

### 4. Ряд карточек (проверка `align_layers` / `distribute_h`)

> Создай три скруглённых прямоугольника 240×320 с отступами, выровняй по верхнему краю и распредели по горизонтали с равными промежутками.

Ожидаемо: три слоя, одинаковый верхний край, равные промежутки между центрами.

## Быстрый чек-лист

- [ ] Деталь не исчезает: цвет отличается от объекта под ней.
- [ ] Усы/брови/рот — обводка (`fill = null`), а не залитая фигура.
- [ ] Нос и глаза не попали в `boolean_op` вместе с головой.
- [ ] Полупрозрачные подложки действительно имеют `opacity < 1`.
- [ ] После серии действий один `Ctrl+Z` возвращает сцену целиком.
- [ ] Ошибка аргумента (например, `radius: -5`) показывается в логе и не ломает сцену.
