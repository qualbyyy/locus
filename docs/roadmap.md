# План развития Locus

Только задачи с высокой отдачей, без перегруза интерфейса и модели данных.

## 1. Базовая графика и слои
- [x] **Градиенты (линейные и радиальные):** поддержка в `fill` и `stroke`, точки и угол на холсте, экспорт в SVG / AI / PSD.
- [x] **Пунктирная обводка:** `dashArray` и `dashOffset` в `StrokeStyle`.
- [x] **Режимы наложения (`blendMode`):** `multiply`, `screen`, `overlay` и др. в `BaseLayer`.
- [x] **Группы слоёв (`Ctrl+G` / `Ctrl+Shift+G`):** `GroupLayer` в сцене, дерево в `LayersPanel`, вход в группу по двойному клику.
- [x] **Несколько артбордов:** создание и экспорт отдельных артбордов в одном `.locus`-файле.
- [x] **Пользовательские шрифты:** загрузка `.ttf` / `.otf` / `.woff2` в проект и проброс в `fontkit` / перевод в кривые.

## 2. Инструменты
- [x] **Shape Builder:** объединение и вырезание пересечений проведением курсора.
- [x] **Карандаш (Freehand)** с авто-сглаживанием и **Нож / Ножницы** для разрезания контура.
- [x] **Текст по контуру (Text on Path):** привязка `TextLayer` к кривой `PathLayer`.
- [x] **Векторизация растра (Image Trace):** перевод `ImageLayer` в редактируемый `PathLayer`.

## 3. Ежедневный UX и надёжность
- [x] **Автосохранение черновика:** тихое локальное сохранение сцены для восстановления после сбоя.
- [x] **Копирование стиля:** перенос `fill`, `stroke`, `effects`, `opacity`, `blendMode` между слоями.
- [x] **Экспорт выделенного и «Copy as SVG»** в буфер обмена.
- [x] **Живое редактирование эффектов в инспекторе:** настройка прямо в правой панели без модального окна.
- [x] **Линейки и ручные направляющие** с привязкой.
- [x] **Каркасный режим (`Ctrl+Y`):** просмотр только контуров без заливок.

## 4. ИИ-ассистент (`Ctrl+K`)
- [x] **Умная перекраска по референсу:** перенос палитры с прикреплённого изображения на слои.
- [x] **Проверка макета (Preflight):** проверка контраста, мелкого кегля для `300 dpi` и объектов за краями артборда.

## 5. Актуализация обучения (`src/tutorial`)
- [x] **Инструменты (главы `curves`, `paths`, `text`, `shapes`):** уроки по `Shape Builder` (`Shift+M`), `Карандашу` (`N`), `Ножу / Ножницам` (`C`), тексту по контуру и `Image Trace`.
- [x] **Эффекты и интерфейс (главы `effects`, `start`, `automation`):** обновить главу `Эффекты` под живое редактирование в инспекторе, добавить линейки/направляющие (`Ctrl+R`) и восстановление черновика.
- [x] **Экспорт и ИИ (главы `export`, `ai`):** добавить «Copy as SVG» (`Ctrl+Shift+C`), экспорт выделенного, перекраску по референсу и проверку макета (Preflight).
- [x] **Проверка:** актуализировать `TUTORIAL_TARGETS` при необходимости и прогнать `tutorial_*.test.ts` + `npm test`.
