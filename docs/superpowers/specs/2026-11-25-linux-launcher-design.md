# Интеграция Locus в Linux-лаунчер

## Намерение

Сделать Locus доступным из системного меню приложений двумя способами:

- через релизные Linux-пакеты, собранные Tauri;
- через локальную установку текущего собранного бинарника без root-доступа.

## Цели

- Сохранять корректное имя `Locus`, идентификатор и иконку приложения.
- Добавить Linux-пакеты `.deb`, `.rpm` и AppImage в стандартную сборку Tauri.
- Добавить повторяемую команду локальной установки бинарника и `.desktop`-файла в `~/.local`.
- Не хранить абсолютные пути пользователя в репозитории.
- Проверить TypeScript-сборку и Tauri bundle-конфигурацию.

## Не входит

- Установка в системные каталоги через `sudo`.
- Автоматический запуск приложения при входе в систему.
- Регистрация ассоциаций файлов `.locus` на этом шаге.

## Подходы

1. Только `.desktop` для AppImage — быстро, но требует ручного размещения бинарника и не покрывает пакетную установку.
2. Только `.deb`/`.rpm` — хорошо для релиза, но неудобно для запуска локальной сборки без установки пакета.
3. **Пакеты Tauri + локальный пользовательский launcher — выбранный вариант.** Он покрывает и релизную установку, и ежедневный запуск текущего бинарника.

## Дизайн

- В `src-tauri/tauri.conf.json` явно настроить Linux bundle targets: `deb`, `rpm`, `appimage`; сохранить существующие иконки.
- Добавить скрипт `scripts/install-linux-launcher.mjs`, который:
  - принимает путь к готовому бинарнику или использует стандартный путь Tauri;
  - копирует бинарник в `~/.local/opt/locus/locus`;
  - копирует Linux PNG-иконку в `~/.local/share/icons/hicolor/128x128/apps/locus.png`;
  - создаёт `~/.local/share/applications/locus.desktop` с абсолютным `Exec` и `Icon=locus`;
  - обновляет desktop/icon cache, если доступна соответствующая утилита;
  - не требует root и идемпотентен.
- Добавить npm-скрипт `install:linux` для запуска этого установщика после `npm run tauri build`.
- Для локального launcher использовать стабильное имя и путь, чтобы обновление бинарника не требовало редактирования `.desktop`.

## Проверка

- `npm run build`.
- `npm run tauri build` или проверка bundle-конфигурации, если системные зависимости не позволяют завершить упаковку.
- Запуск `npm run install:linux -- <path-to-binary>` и проверка наличия:
  - `~/.local/opt/locus/locus`;
  - `~/.local/share/applications/locus.desktop`;
  - иконки в `~/.local/share/icons/hicolor/128x128/apps/locus.png`.
- Проверить, что `.desktop` содержит корректные `Type`, `Name`, `Exec`, `Icon`, `Categories` и `Terminal=false`.

## Решения по умолчанию

- Установка выполняется только в каталог текущего пользователя.
- Основная категория приложения — `Graphics;VectorGraphics;`.
- Лаунчер запускает установленную копию, а не бинарник из `src-tauri/target`, чтобы последующие сборки не ломали существующую запись меню.
