# Дизайн: глобальное контекстное меню, масштаб холста и «О приложении»

## Намерение

Заменить стандартное контекстное меню браузера во всём окне Locus единым меню приложения, не допустить масштабирования всего интерфейса при `Ctrl/Cmd + колесо` или pinch-жесте тачпада и расширить настройки разделом «О приложении».

## Цели

- Перехватывать `contextmenu` во всём приложении и показывать собственное меню в позиции курсора.
- Показывать в меню действия, соответствующие объекту или выделению, включая отдельный пункт «ИИ» для объектов.
- Сохранить редактирование текста в полях ввода через собственные действия копирования, вставки, вырезания и выделения.
- Масштабировать только Paper-холст по `Ctrl/Cmd + wheel` и pinch-gesture; не менять масштаб WebView и интерфейса.
- Добавить вкладку «О приложении» с названием, версией, лицензией, создателем, контактами, описанием, ссылками, сторонними компонентами и безопасным копированием диагностических сведений.
- Убрать из «О приложении» отдельный блок «Возможности».
- Добавить кнопку «Обучение» в нижний футер окна настроек как неактивную заготовку без содержимого.

## Не входит в задачу

- Реализация ИИ-инструмента или нового CommandBar. Пункт «ИИ» в меню будет доступен как точка входа и вызовет существующее уведомление-заглушку до реализации Этапа 5.
- Онлайн-проверка обновлений, аналитика, отправка диагностических данных и сетевые запросы из «О приложении».
- Заполнение неподтверждённых контактных данных или лицензии выдуманными значениями: при отсутствии данных отображается нейтральное «Не указана» / «Не добавлены».

## Антицели

- Не возвращать браузерное меню в отдельных частях приложения из-за случайно не обработанного `contextmenu`.
- Не перехватывать обычный `wheel` без модификатора как масштабирование.
- Не копировать в диагностические сведения API-ключи, содержимое проектов или данные ассетов.

## Ограничения проекта

- Zustand и существующие команды остаются единственным способом менять сцену.
- Paper.js продолжает отвечать за hit-test холста, а React — за меню и настройки.
- Нельзя добавлять новые зависимости.
- Визуальный стиль сохраняет бумажную тему: плоские панели, границы `1px`, без тяжёлых теней и blur.

## Подходы

### Вариант A — меню только на холсте

Меньше изменений, но стандартное меню останется в панелях и полях приложения. Не соответствует требованию единого поведения во всём окне.

### Вариант B — глобальное меню приложения (выбран)

Корневой обработчик Locus отменяет стандартный `contextmenu`. Контекст холста передаётся из Paper.js через hit-test, а для остальных областей используется DOM-контекст и текущее выделение. Один компонент меню позиционируется через `fixed`, ограничивается границами окна, закрывается по клику снаружи и `Escape`. Для `input`, `textarea` и contenteditable меню содержит текстовые действия.

Это соответствует требованию пользователя и позволяет добавить одинаковую точку входа «ИИ» для любого объекта.

### Вариант C — только блокировка браузерного меню

Не даёт пользователю полезных действий и не используется.

## Поведение контекстного меню

- На объекте холста меню использует слой, найденный Paper.js hit-test; если hit-test не нашёл объект, используется текущее выделение.
- В списке слоёв меню использует слой строки, если он доступен, иначе текущее выделение.
- На пустой области доступны действия вставки, выделения и создания/открытия команд.
- Для выбранных объектов доступны существующие операции: копирование, вырезание, дублирование, удаление, изменение порядка, снятие выделения.
- Для всех объектов отображается пункт «ИИ…». Он вызывает существующий callback открытия CommandBar/уведомления, передавая контекст выделения через текущий selection state; отдельный сетевой вызов не добавляется.
- В текстовых полях действия работают с выделенным текстом и не вызывают команды сцены.
- Меню не меняет сцену напрямую: оно вызывает существующие callbacks и команды App.

## Масштабирование

- `PaperCanvas` обрабатывает только `WheelEvent`, у которого установлен `ctrlKey` или `metaKey`.
- Для такого события выполняются `preventDefault()`, масштабирование к позиции курсора и обновление процента масштаба.
- Обычный wheel не масштабирует холст.
- На уровне App/WebView `Ctrl/Cmd + wheel` блокируется над остальными областями окна, чтобы WebView не масштабировал весь интерфейс.
- `gesturestart` и связанные браузерные жесты также отменяются на уровне окна.

## «О приложении»

В `SettingsModal` добавляется вкладка с иконкой информации. Внутри остаются компактные секции:

- идентичность: Locus, версия из конфигурации проекта, тип сборки;
- сведения о лицензии, создателе и контактах;
- краткое описание приложения;
- ссылки на документацию, репозиторий, сообщения об ошибках и контакты, если они заданы;
- список ключевых сторонних компонентов без блока «Возможности»;
- кнопка копирования безопасной диагностики: версия, платформа, ОС и режим запуска без секретов и файлов пользователя.

В нижнем футере модального окна добавляется кнопка «Обучение». Пока она не открывает содержимое и отображается как заготовка для будущего раздела.

## Что остаётся реализовать

- Компонент глобального контекстного меню и состояние его позиции/контекста.
- Передача hit-test результата из `PaperCanvas` в App.
- Текстовые операции меню для редактируемых элементов.
- Уточнение обработчиков wheel и WebView zoom.
- Вкладка «О приложении», футер с кнопкой «Обучение» и безопасная диагностика.
- Тесты на меню/масштабирование/санитизацию отображаемых сведений и стандартные `tsc`, Vitest, build.
