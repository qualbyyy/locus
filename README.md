# Locus

Локальный редактор векторной графики для десктопа — быстрый и лёгкий аналог Adobe Illustrator или Figma со светлой «бумажной» темой и упором на автоматизацию рутины.

Locus работает полностью на твоей машине: проекты, изображения и настройки никуда не отправляются.

## Возможности

- **Вектор и слои:** кривые Безье, перо (`P`), карандаш с авто-сглаживанием (`N`), конструктор фигур (`M`), нож и ножницы (`C`), опорные точки и усики (`A`), составные контуры (`Ctrl+8`), булевы операции (`unite`, `subtract`, `intersect`, `exclude`, `divide`), обводка в кривые, параллельный контур, упрощение и отражение.
- **Графика и стиль:** линейные и радиальные градиенты в заливке и обводке (точки и угол прямо на холсте), пунктирная обводка, 16 режимов наложения (`blendMode`), группы слоёв (`Ctrl+G` / `Ctrl+Shift+G`) со входом по двойному клику, несколько артбордов в одном `.locus`-файле, копирование и вставка стиля (`Ctrl+Alt+C` / `Ctrl+Alt+V`).
- **Умные примитивы и векторизация:** эллипс (круг), скруглённый прямоугольник, многоугольник, звезда и капсула с живыми параметрами (`B`), а также трассировка растра (`Image Trace` в Ч/Б и цветном режиме).
- **Текст и шрифты:** 6 встроенных семейств с кириллицей (`Inter`, `Manrope`, `Golos Text`, `Playfair Display`, `JetBrains Mono`, `Unbounded`), загрузка пользовательских шрифтов `.ttf` / `.otf` / `.woff2` в проект, трекинг, регистр, текст по контуру и перевод в кривые (`Ctrl+Shift+O`).
- **Эффекты в реальном времени:** живое редактирование прямо в инспекторе без модальных окон — `Warp`, `ZigZag`, `Roughen`, `Round Corners`, 3D-поворот и экструзия, размытие по Гауссу, падающая тень и внешнее свечение, разбор оформления (`Expand`).
- **Маски, линейки и надёжность:** Clipping Mask, смарт-гайды, линейки и ручные направляющие с привязкой (`Ctrl+R`), сетка (`Ctrl+'`), каркасный режим (`Ctrl+Y`) и автосохранение черновиков с восстановлением после закрытия.
- **Импорт и экспорт:** импорт `.svg` в редактируемые векторные, текстовые и масочные слои (через меню или Drag & Drop), сохранение `.locus` (ZIP с ресурсами и шрифтами), экспорт `.svg`, `.ai` (векторный PDF), многослойного `.psd`, растра `.png` / `.jpg` (`Ctrl+Shift+E`), экспорт только выделенного и `Copy as SVG` (`Ctrl+Shift+C`).
- **Обучение:** встроенная «Академия» (`F1`) с пошаговыми уроками, поиском и подсветкой элементов интерфейса (`data-tour`).
- **ИИ-ассистент (`Ctrl+K`):** управление сценой через Tool Calling, вложения изображений, умная перекраска макета по палитре референса и проверка макета (`Preflight`: контраст текста, минимальный кегль для `300 dpi`, выход за артборд). Поддержка Gemini, Anthropic, Ollama и OpenAI-совместимых API; вся серия действий откатывается одним `Ctrl+Z`.

## Стек

React 19, TypeScript, Vite, Tailwind CSS v4, Zustand + zundo, Paper.js, Tauri v2 (Rust). PDF собирается через `pdf-lib` + `@pdf-lib/fontkit`, PSD — через `ag-psd`.

## Требования

- Node.js 20+ и npm
- Rust (stable) и Cargo
- **Linux:** пакеты Tauri v2 (`webkit2gtk-4.1`, `gtk+-3.0`, `librsvg-2.0`, `libsoup-3.0`, `openssl`) — см. [документацию Tauri](https://v2.tauri.app/start/prerequisites/)
- **Windows** (отдельная сборка): WebView2 и MSVC Build Tools

## Запуск

```bash
npm install
npm run tauri dev
```

Веб-версия без Tauri (часть нативных файловых диалогов работает через браузерные API):

```bash
npm run dev
```

На Wayland бинарник автоматически выставляет `WEBKIT_DISABLE_DMABUF_RENDERER=1` при старте (если переменная не задана вручную).

## Сборка, тесты и установка

```bash
npm test                # unit-тесты + реальный рендер Canvas 2D (@napi-rs/canvas)
npm run test:e2e        # браузерный E2E в Playwright (требует собранный dist/)
npm run build           # проверка TypeScript и сборка фронта (dist/)
npm run tauri build     # сборка десктопного приложения и пакетов
npm run install:linux   # установка бинарника, ~/.local/bin/locus и .desktop-ярлыка
```

Для Linux (`.deb` / `.rpm` / `.AppImage`) и Windows (`.exe` NSIS / `.msi`) сборка описана в `.github/workflows/release.yml`.

## Горячие клавиши (кратко)

- Инструменты: `V` — выделение, `A` — узлы, `P` — перо, `N` — карандаш, `B` — умная фигура, `M` — конструктор фигур, `C` — нож/ножницы, `T` — текст, `E` — пипетка, `I` — изображение.
- Правка и слои: `Ctrl+Z` / `Ctrl+Shift+Z` — отмена и повтор, `Ctrl+G` / `Ctrl+Shift+G` — группа/разгруппировать, `Ctrl+Shift+C` — Copy as SVG, `Ctrl+Alt+C` / `Ctrl+Alt+V` — копировать/вставить стиль, `Ctrl+Shift+O` — текст в кривые.
- Вид и утилиты: `Space + Drag` — панорама, `Ctrl+0` — вписать артборд, `Ctrl+R` — линейки, `Ctrl+Y` — каркас, `Ctrl+K` — ИИ-ассистент, `F1` — обучение.

Полный настраиваемый список — в настройках (`Ctrl+,`) на вкладке «Горячие клавиши».
