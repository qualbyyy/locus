# Locus

Локальный редактор векторной графики для десктопа — быстрый и лёгкий аналог Adobe Illustrator со светлой «бумажной» темой и упором на автоматизацию рутины.

Locus работает полностью на твоей машине: проекты, изображения и настройки никуда не отправляются.

## Возможности

- **Векторный инструментарий:** кривые Безье, перо, опорные точки и усики, составные контуры, булевы операции (`unite`, `subtract`, `intersect`, `exclude`, `divide`), обводка в кривые, параллельный контур, упрощение и отражение.
- **Умные примитивы:** клякса, эллипс, скруглённый прямоугольник, многоугольник и звезда с живыми параметрами.
- **Текст:** шесть встроенных шрифтов с кириллицей, два начертания, трекинг, выравнивание, перевод текста в кривые.
- **Маски и слои:** Clipping Mask в один клик, порядок слоёв, видимость, блокировка, выравнивание и распределение.
- **Автоматика:** сглаживание, шум, случайное искажение узлов, палитры, смарт-гайды и привязки.
- **Экспорт:** `.locus` (ZIP с ресурсами), `.svg`, `.ai` (векторный PDF) и многослойный `.psd`.

- **ИИ-ассистент:** командная строка `Ctrl+K` с Tool Calling; ИИ управляет сценой через 14 инструментов редактора (фигуры, текст, линии и обводки, маски, палитры, выравнивание, булевы операции). К запросу можно прикреплять изображения для vision-моделей; для моделей без поддержки картинок приложение прямо об этом сообщает. Провайдеры: Gemini, Anthropic, Ollama и OpenAI-совместимые API (включая DeepSeek, OpenRouter, LM Studio). Вся серия действий откатывается одним `Ctrl+Z`.

## Стек

React 19, TypeScript, Vite, Tailwind CSS v4, Zustand + zundo, Paper.js, Tauri v2 (Rust). PDF собирается через `pdf-lib` + `@pdf-lib/fontkit`, PSD — через `ag-psd`.

## Требования

- Node.js 20+ и npm
- Rust (stable) и Cargo
- Linux: пакеты Tauri v2 (`webkit2gtk-4.1`, `gtk+-3.0`, `librsvg-2.0`, `libsoup-3.0`, `openssl`) — см. [документацию Tauri](https://v2.tauri.app/start/prerequisites/)
- macOS: Xcode Command Line Tools; Windows: WebView2 и MSVC Build Tools

## Запуск

```bash
npm install
npm run tauri dev
```

Если на Linux с Wayland/WebKitGTK окно открывается чёрным, запускай так:

```bash
WEBKIT_DISABLE_DMABUF_RENDERER=1 npm run tauri dev
```

Веб-версия без Tauri (часть файловых операций недоступна):

```bash
npm run dev
```

## Сборка и проверки

```bash
npm test
npm run build
npm run tauri build
```

## Горячие клавиши (кратко)

`V` — выделение, `A` — узлы, `P` — перо, `B` — умные фигуры, `T` — текст, `I` — изображение, `E` — пипетка, `Space + Drag` — панорамирование, `Ctrl/Cmd + колесо` — масштаб холста, `Ctrl+Z` / `Ctrl+Shift+Z` — отмена и повтор, `Ctrl+0` — вписать артборд. Полный список — в окне настроек на вкладке «Горячие клавиши».
